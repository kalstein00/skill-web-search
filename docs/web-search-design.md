# 웹 검색 중계 설계

2026-09-08 사용자가 HTTP 사용을 포함한 전체 설계를 확정했다. 구현과 실행 검증은 아직 수행하지 않았다.

## 확정 사항

- 내부망 PC의 Cline이 스킬을 통해 같은 네트워크의 인터넷 PC에 웹 정보 접근을 요청한다.
- 서버는 Windows 독립 실행파일로 제공하며 Cline 설치나 실행에 의존하지 않는다.
- 클라이언트는 서버 접속 주소를 `.env`에서 읽는다.
- 서버는 검색 결과와 선택한 페이지 본문을 출처 URL과 함께 반환한다. 최종 해석은 내부망 Cline이 수행한다.
- 각 요청은 독립적이며 요청 간 대화 이력을 유지하지 않는다.
- 서버 애플리케이션은 검색어, 페이지 본문, 결과를 디스크에 저장하지 않는다. 운영 로그에는 처리 시간과 성공·실패 정도만 남긴다. 브라우저 임시 데이터의 수명은 아래 별도 규칙을 따른다.
- 내부망 PC가 보내는 웹 정보 요청의 내용은 검색어 또는 대상 URL로 제한한다. 프로젝트 파일이나 전체 대화는 보내지 않는다.
- 검색은 외부 검색 API 없이 헤드리스 웹브라우저로 수행한다. 무료 사용만 허용한다.
- 첫 버전의 본문 조회는 일반 공개 HTML로 한정한다. PDF, JavaScript 실행이 필요한 본문, 로그인 페이지는 지원 범위 밖이며 해당 사유를 반환한다.
- 클라이언트는 공유 토큰으로 인증한다. 서버 주소와 토큰을 클라이언트 `.env`에 저장한다.
- 본문 조회는 공개 인터넷 주소만 허용한다. 로컬·사내 IP 주소를 차단하며 리다이렉트 대상에도 같은 규칙을 적용한다.
- 기본 검색엔진은 Google이다.
- CAPTCHA 또는 접근 차단이 발생하면 해당 요청을 실패로 반환한다. 검색 결과가 없는 정상 응답과 구분한다.
- 브라우저 임시 프로필·캐시는 요청 종료 시 삭제한다. 비정상 종료로 남은 임시 데이터는 다음 서버 시작 시 정리한다. 실행 중 임시 디스크 기록은 허용한다.
- 서버 실행파일과 전용 브라우저를 배포 폴더로 함께 제공한다. 사용자는 서버 실행파일 하나를 실행하며 Cline이나 별도 개발 도구 설치를 요구하지 않는다.
- 클라이언트 측에서는 Windows 또는 Linux의 Cline이 스킬을 사용할 때 서버에 접속한다. macOS는 지원 범위 밖이다.
- 클라이언트는 현재 프로젝트 루트의 `.env`에서 서버 주소와 공유 토큰을 읽는다. 필요한 설정이 없으면 설정 오류를 반환한다.
- 서버 프레임워크는 FastAPI를 사용한다.
- 서버는 사용자가 실행파일을 직접 실행하고 종료한다. 첫 버전에는 Windows 서비스 등록을 포함하지 않는다.
- 클라이언트 호출 도구는 Python 스크립트로 제공하며 Windows·Linux에서 `uv run`으로 실행한다.
- 검색과 본문 조회는 별도 호출이다. 검색은 기본 5개 결과의 제목·URL·요약을 반환하고, Cline이 선택한 URL의 본문을 추가 요청한다.
- 서버는 한 번에 하나의 요청만 처리한다. 처리 중 새 요청은 `busy`로 반환하며 클라이언트의 무제한 자동 재시도는 두지 않는다.
- 요청당 처리 제한은 30초다. 시간 초과는 별도 오류로 반환한다.
- 본문 응답은 최대 2만 자다. 잘린 본문에는 `truncated` 표시와 출처 URL을 포함한다.
- 내부망 PC에는 Python과 uv 사전 설치를 요구한다. 클라이언트는 Python 표준 라이브러리만 사용하며 실행 중 패키지나 Python 다운로드를 시도하지 않는다.
- Cline 스킬이 클라이언트 호출 시 프로젝트 루트를 명시적으로 전달한다. 클라이언트는 해당 위치의 `.env`만 읽는다.
- 서버 수신 주소·포트·공유 토큰은 서버 실행 시 인자로 전달한다.
- 클라이언트는 자동 재시도 없이 오류를 반환한다.
- 서버는 클라이언트 연결 종료를 감지하거나 30초 제한에 도달하면 해당 브라우저 작업을 취소하고 임시 데이터를 정리한다.
- 클라이언트 표준 출력은 JSON으로 통일하고 실행 진단은 표준 오류로 분리한다.
- 검색 결과 없음은 정상 응답이다. 인증 실패, `busy`, CAPTCHA, 접근 차단, 시간 초과, 지원하지 않는 페이지는 구분된 오류로 반환한다.
- 첫 버전 서버 배포 대상은 Windows x64다.

## 전송 방식

- 첫 버전은 사내 방화벽 안에서 HTTP로 제공한다. 공유 토큰과 검색어를 전송 중 암호화하지 않으며 HTTPS 인증서 배포는 첫 버전 범위 밖이다.

## 첫 버전 완료 기준

- Windows·Linux의 Cline에서 스킬로 Google 검색과 본문 조회에 성공한다.
- 내부망 클라이언트는 외부 인터넷 접근이나 패키지 다운로드 없이 동작한다.
- Cline·Python이 설치되지 않은 Windows x64 PC에서 서버 배포본을 실행한다.
- 인증 실패, 동시 요청, CAPTCHA, 시간 초과를 구분해 처리한다.
- 내부 주소와 그 주소로 향하는 리다이렉트를 차단한다.
- 본문 길이 제한과 잘림 표시를 확인한다.
- 요청 종료·실패 시 임시 데이터를 정리하고, 비정상 종료 잔여물은 다음 시작 시 정리한다.

위 항목은 합의한 검증 목표이며 현재 통과한 테스트 결과를 뜻하지 않는다.
