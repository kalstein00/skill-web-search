# Windows 검증 기록

## #2 공개 HTML 본문 조회

- 환경: Windows, Python 3.12.14. 개발 환경에 uv 0.12.11을 준비했습니다.
- 공개 클라이언트 프로세스와 실제 Uvicorn/FastAPI 서버를 연결한 통합 테스트 22개 통과.
- 일반 HTML, 20,000자와 20,001자, 비HTML, 로그인 폼, JavaScript 필요 안내, 접근 차단, 설정 누락과 인증 실패, IPv4·IPv6·숫자 변형 내부 주소 차단을 확인했습니다.
- mypy와 Ruff 통과.
- `https://example.com` 실제 연결은 시간 초과가 발생했습니다. 통제된 HTML 테스트 성공과 라이브 성공은 구분하며, 아직 라이브 본문 조회 성공을 확인하지 못했습니다.
- 이어서 실제 CLI → 서버 → `https://www.google.com` 경로에서 종료 코드 0, `ok: true`, 본문 85자와 출처 URL 반환을 확인했습니다. 따라서 공개 HTML 라이브 조회는 확인되었고 example.com의 개별 연결 실패는 남겨 둡니다.
- 리뷰에서 발견한 포트 설정 예외와 HTTP charset 무시를 수정했습니다. 한국어 EUC-KR 본문, 비공개·혼합 DNS 응답, 내부 리다이렉트, DNS 재조회 없이 검증한 IP로 연결하는 경우를 추가 검증했습니다.
- Linux·WSL 검증은 사용자 요청에 따라 제외합니다.
