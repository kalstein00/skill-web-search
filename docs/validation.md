# Windows 검증 기록

## #2 공개 HTML 본문 조회

- 환경: Windows, Python 3.12.14. 개발 환경에 uv 0.12.11을 준비했습니다.
- 공개 클라이언트 프로세스와 실제 Uvicorn/FastAPI 서버를 연결한 통합 테스트 22개 통과.
- 일반 HTML, 20,000자와 20,001자, 비HTML, 로그인 폼, JavaScript 필요 안내, 접근 차단, 설정 누락과 인증 실패, IPv4·IPv6·숫자 변형 내부 주소 차단을 확인했습니다.
- mypy와 Ruff 통과.
- `https://example.com` 실제 연결은 시간 초과가 발생했습니다. 이 시점에는 라이브 본문 조회 성공을 확인하지 못했습니다.
- 이어서 실제 CLI → 서버 → `https://www.google.com` 경로에서 종료 코드 0, `ok: true`, 본문 85자와 출처 URL 반환을 확인했습니다. 따라서 공개 HTML 라이브 조회는 확인되었고 example.com의 개별 연결 실패는 남겨 둡니다.
- 리뷰에서 발견한 포트 설정 예외와 HTTP charset 무시를 수정했습니다. 한국어 EUC-KR 본문, 비공개·혼합 DNS 응답, 내부 리다이렉트, DNS 재조회 없이 검증한 IP로 연결하는 경우를 추가 검증했습니다.
- Linux·WSL 검증은 사용자 요청에 따라 제외합니다.

## #3 Google 검색

- 전용 Chromium 151.0.7922.34, Playwright 1.62.0으로 실제 브라우저 → 통제된 외부 웹 응답을 연결했습니다.
- 실제 클라이언트·서버·브라우저 경로에서 검색 성공, 5개 제한, 적은 결과, 빈 결과, CAPTCHA, 차단, 미인식 화면을 검증했습니다.
- 검색 테스트 13개를 전체 및 변경된 하위 집합으로 실행해 통과를 확인했습니다. 내부 스크립트·내부 리다이렉트 차단, 다른 출처 문서로 이동 후 상대 JavaScript 주소 처리, 성공·실패 뒤 임시 프로필 삭제, 브라우저 미설치 오류를 포함합니다.
- 리뷰에서 지적한 브라우저 리다이렉트 출처 보존, 브라우저 시작 실패의 JSON 반환, 정상 검색 내용에 포함된 오류 문구 오인, 인접 결과 요약 혼입을 수정했습니다.
- 실제 Google 검색 `Python documentation`은 CAPTCHA를 반환했습니다. 차단을 우회하거나 성공으로 표시하지 않았습니다. 따라서 #3의 실제 검색 성공 기준과 이후 최종 검색 성공 기준은 아직 충족되지 않았습니다.
- 라이브 검증은 `WEB_RELAY_LIVE=1` 환경에서 `uv run pytest tests/test_live.py -s`로 별도 실행합니다. 기본 테스트의 외부 응답 통제 성공과 구분합니다.

## #4 취소와 데이터 수명

- 검색·본문의 공통 busy, 시간 초과·연결 중단 후 외부 작업 취소, 프로필 삭제와 후속 본문 조회 복구를 확인했습니다.
- 별도 Windows 서버 프로세스에서 실제 Chromium을 실행한 뒤 서버 PID를 강제 종료했습니다. 자식 Chromium·드라이버 프로세스가 종료되고, 동일 데이터 경로로 재시작했을 때 잔여 프로필이 삭제됨을 확인했습니다.
- 코드 리뷰에서 검색 브라우저의 25초 탐색 제한이 일반 브라우저 오류로 분류되는 문제를 발견해 제거했습니다. 검색과 본문 모두 서버의 30초 요청 제한을 사용합니다.
- 기본 30초 본문 요청 제한과 로그의 요청 내용·토큰 부재를 확인했습니다. 브라우저 시작 직후 취소 테스트에서 발견한 드라이버 누수를 수정하고, 자식 프로세스와 프로필이 남지 않는 회귀 테스트를 통과했습니다.
- 기본 30초 검색 제한도 별도로 통과했습니다(테스트 실행 약 31.5초, 서버 시작·종료 포함). 브라우저 시작의 별도 제한 시간 오류도 `timeout`으로 분류합니다.
