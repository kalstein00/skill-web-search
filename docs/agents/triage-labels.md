# Triage labels

| 역할 | 실제 라벨 | 의미 |
| --- | --- | --- |
| needs-triage | needs-triage | 관리자의 검토 필요 |
| needs-info | needs-info | 제보자의 추가 정보 대기 |
| ready-for-agent | ready-for-agent | 명세가 준비되어 에이전트 작업 가능 |
| ready-for-human | ready-for-human | 사람이 구현해야 함 |
| wontfix | wontfix | 처리하지 않음 |

스킬이 triage 역할을 언급하면 이 표의 실제 라벨을 사용한다.
